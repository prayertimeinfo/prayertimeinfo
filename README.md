# PrayerTime.info
PrayerTime.info provides accurate daily prayer times calculated by the Umm al-Qura method. Features include a 30-day prayer timetable, Qibla direction, Hijri calendar, and automatic daily updates for cities across Saudi Arabia and worldwide.
- Homepage: https://prayertime.info/
- Jeddah prayer times: https://prayertime.info/ar/saudi-sa/jeddah/
